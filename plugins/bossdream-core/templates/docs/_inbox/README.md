# _inbox — buzon de documentacion informal

Tira aqui tus notas tal cual: ideas, decisiones, explicaciones, sin formato ni estructura. Un archivo por tema o uno solo, da igual.

Cuando termines, ejecuta `/docs-rewrite`. Convierte esto en documentacion IA-friendly (Diataxis + ADR), **sin perder tus ideas ni inventar nada**: lo que no pueda anclar al codigo te lo pregunta, no lo adivina.

Al procesarse, el contenido migra a `human-explanations/`, `to-skills/`, `catalog/`, `concepts/` o `adr/`, y este buzon queda vacio.
